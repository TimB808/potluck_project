**Final project for Le Wagon's Data Science bootcamp #1181**

The Pot Luck website applies NLP embedding and K-Means clustering, deployed through Docker and Google Cloud, to allow users to search for recipes based on the ingredients they have available. It also offers a 'creative' search feature for those seeking inspiration.
